# Архитектура финансово-экономической модели 00–07

## Сквозная цепочка

```
00 предпосылки (инфляция, НДС, налоги, WACC, COE, g)
  ↓
01 клиенты и выручка  ──┐
  ↓                     │
02 команда, COGS, OPEX ←┘ (получает из 01 аккаунты/транзакции)
  ↓
03 CAPEX, амортизация, оборотный капитал (NWC)
  ↓
04 потребность в деньгах, источники, долг, runway
  ↓
05 ОПУ + ОДДС + Баланс + налоги  (официальная отчётность модели)
  ↓
06 DCF: FCFF, EV, IRR, PP, break-even, инвестор, риски
  ↓
07 коэффициенты и итоговая аналитика
```

Правила направления данных: 00 → 01…06 (но **не** напрямую в 07); 06 получает налог на прибыль из 00, а не через 05; 07 анализирует результаты 04–06.

## Технические коды

Префиксы: `ENV` — среда; `TAX` — налоги и начисления; `VAL` — оценка; `REV` — выручка; `COST` — затраты; `MKT` — маркетинг; `HR` — персонал; `WC` — оборотный капитал; `ASSET` — активы; `FIN` — финансирование; `FS` — финотчётность; `CF` — денежный поток; `BS` — баланс; `INV` — инвестор; `BE` — безубыточность; `RISK` — риски; `AN` — аналитика; `CTRL`/`CHECK` — контроль. Суффиксы: `_A` годовой, `_Q` квартальный, `PER` на единицу, `0` — базовое значение до индексации.

**Код — главный ключ при переносе между файлами**; русское название только для контроля.

## Типовая структура листов блока

| Лист | Роль |
|---|---|
| Входы | Межфайловые значения из предыдущих блоков (не переопределять) |
| Драйверы / Допущения / Финансирование / Цифровые активы / Риски | Ручной ввод |
| Расчет / OPEX / ОПУ / Эффективность / Аналитика | Автоматические формулы |
| Выходы | Интерфейс для следующих блоков (вручную не править) |
| Связи | Карта передачи кодов |
| Контроль | Проверки (должно быть OK) |
| Пояснения / Источники РБ | Справка и нормативные ориентиры |

## Цветовая логика

Жёлтая заливка + синий шрифт — ввод; чёрный — формула внутри листа; зелёный — ссылка на другой лист; тёмно-синий заголовок — раздел.

## Агрегирование квартальной модели в годовой бизнес-план

- **Потоки** (выручка, COGS, OPEX, EBITDA, EBIT, чистая прибыль, CAPEX, CFO/CFI/CFF, FCFF, маркетинг, ФОТ, проценты, налоги) — сумма 4 кварталов.
- **Остатки** (Cash, AR, Deferred Revenue, Fixed Assets, Debt, Equity, AP, NWC, Headcount) — значение последнего квартала.
- **Коэффициенты** — не усреднять вручную, брать из `07 → Аналитика`.
- Квартальный churn в годовой: `1 − (1 − churn_q)^4` (не умножать на 4).

## Ключевые формулы

- `REV.NET = REV.SUB_NET + REV.TXN_NET`; `SUB_NET ≈ SUBS × SUB_PRICE`; `TXN_NET ≈ TXN × TXN_PRICE`
- `Gross Profit = Revenue − COGS`; `EBITDA = Gross Profit − OPEX`; `EBIT = EBITDA + Grant − Amort`; `PBT = EBIT − Interest`; `Net Income = PBT − Profit Tax`
- `NWC = Оперативные оборотные активы − Оперативные обязательства`; `ΔNWC = NWC_end − NWC_open`
- `Funding Need = max(0; MinCash − CashBeforeFinancing)`; `Funding Gap = max(0; Need − Plan)`
- `Net Cash Flow = CFO + CFI + CFF`; `Closing Cash = Opening Cash + Net CF`
- `FCFF = NOPAT + Amort − CAPEX − ΔNWC`; `PV = FCFF × DF`; нужно `WACC > g`
- `Equity Value = EV + Cash − Debt`; `Risk-adjusted EV = Base EV − Expected Loss`
- `Break-even Revenue = Fixed / CM rate`; `Margin of Safety = (Actual − BE) / Actual`
- `Debt Service = Principal + Interest`; `CHECK.BALANCE = Assets − Liabilities − Equity = 0`
