## Правила владелицы из прошлых работ (применять и здесь)

Из `E:\ИИТ\ЭлектронныйБизнес\HANDOFF.md` и инструкций репозитория DSLKit:

1. Никаких меток ИИ в тексте, коде, документах и коммитах (в том числе строк соавторства и пометок об автоматической генерации). Автор документов — К. А. Хаджинова.
2. Оформление отчётов — СТП БГУИР 01-2024: Times New Roman 14, интервал 18 пт, абзац 1,25, поля 30/15/20/20 мм.
3. Titul: Факультет повышения квалификации и переподготовки; кафедра микропроцессорных систем и сетей; преподаватель Беляцкая Т. Н. (для ЭБ — уточнить для ЭЭБ).
4. Excel с диаграммами править только через COM (PowerShell), не openpyxl: openpyxl теряет графики. *В этой папке: файл 07 содержит графики и исправлен точечно в XML (графики сохранены); файл 00 графиков не содержит.*
5. Не придумывать данные: если данных нет — маркер/пометка, источник и тип данных (FACT/BENCHMARK/PROXY/ASSUMPTION).
6. Нельзя вливать в `main` без решения владелицы; секреты — только в `.env`.
