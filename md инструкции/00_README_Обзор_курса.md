# Курс «Электронный бизнес» (ЭЭБ): обзор материалов

## О чём курс

Итоговая работа — **курсовая: бизнес-план электронного бизнеса / цифрового продукта** (например, портал дополнительного образования взрослых). Курсовая — самостоятельное письменное исследование под руководством научного руководителя и итог по дисциплине.

Расчётное ядро бизнес-плана — **финансово-экономическая модель 00–07** (Excel, Республика Беларусь, горизонт 2026–2030, поквартально, тыс. BYN). Для каждого блока модели есть: Excel-файл, инструкция по заполнению, теория к Excel, короткие промпты для Gemini (сбор внешних данных). Дополнительно — упрощённый Excel-дашборд 01–07 и шаблон текстового описания модели.

## Два варианта темы (из презентации КУРСОВАЯ.pptx)

1. **Бизнес-план электронного бизнеса** в сфере … (экономико-финансовая модель, бизнес-проект ПВТ), цель — внедрение бизнеса на рынок.
2. **Бизнес-проект цифрового продукта / услуги** (например, бронирование мест в спортивных залах) в рамках организации / действующего портала / нового бизнеса.

## Рекомендуемая последовательность

1. Прочитать `01_Архитектура_модели_00-07.md` и `03_Правила_работы_с_данными_и_Gemini.md`.

3. Выполнить работы 00 → 07 по порядку (каждая — по своему README).
