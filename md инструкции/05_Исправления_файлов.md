# Исправления поломанных файлов

Проверялись все 15 xlsx из `Модель.rar` (поиск ошибок `#REF!/#VALUE!/…`, ссылок на несуществующие листы, формул, выбивающихся из ряда, формул поверх вводимых значений, несоответствия формата числа единице измерения) и все docx/pptx (открываются без ошибок).

**Оригиналы в `исходные условия/` не изменялись.** Исправленные файлы лежат в `работы/…/excel/`. После правок включён пересчёт формул при открытии (Excel пересчитает книгу сам; при запросе сохранить изменения при закрытии — это нормально).

## Замечания (не ошибки, оставлены как есть)

- В ряде файлов (01-2, 02-1, 04, Дашборд «ИСПРАВЛЕННЫЙ_ШАБЛОН», 00 после правки) формулы сохранены без кэшированных значений — до первого открытия в Excel числа не видны. Это штатно: Excel рассчитает при открытии.
- В файле «Дашборд ЗАПОЛНЕННЫЙ_ПРИМЕР» и «ИСПРАВЛЕННЫЙ_ШАБЛОН» первые периоды содержат формулы-начальные условия (`=D5+…`) — это логика, а не ошибка.
- `Копия 00/01-1/02/03…xlsx` — пересохранённые варианты основных файлов (другой формат ссылок на листы, лишние числовые форматы). `Копия 00` содержит те же поломки (`#VALUE!` в «Допущения»); `Копия 01-1` содержит **другие входные данные трафика** конкурентов. Для работы использовать основные файлы, копии оставлены только в `исходные условия/`.
- `Пояснение_блока_06…(1).docx` — точная дубликатная копия файла без «(1)».

## Проверка в Microsoft Excel (COM, полный пересчёт)

Все 13 файлов открыты в Excel 16, выполнен `CalculateFull`, значения проверены на ошибки, затем файлы сохранены самим Excel (в них теперь есть актуальные значения формул, диаграммы сохранены). Результат: ошибок значений — 0 во всех файлах. Найдено и исправлено при пересчёте:

|---|---|---|---|
| 07_Финансовая_аналитика | «Контроль», C16 | `MIN(Входы!D51:H51/Входы!D7:H7)` — деление диапазонов внутри `MIN` без массивного ввода давало `#ЗНАЧ!` | Формула переписана через `AGGREGATE(15;6;…;1)`, работает в любой версии Excel |
| 00_Контур_и_предпосылки | «Допущения», строки 8–15 | Перепутанные заливки и жирность строк (НДС, Cost of Equity, g), лишняя заливка за колонкой J | Форматы строк выровнены по соседним строкам, хвост K:W очищен |
