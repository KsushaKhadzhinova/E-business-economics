# Блок 04. Финансирование
Короткие последовательные промпты для бесплатной Gemini

Сбор данных за пределами модели • ручная подстановка в Excel • контроль источников • верификация выдачи • фокус: стартап

## Как пользоваться

- Не загружайте Excel в бесплатную Gemini. Работайте одним коротким запросом за сообщение и переносите в модель только финальные проверенные входные таблицы.

- В начало каждого запроса вставляйте бизнес-постановку. Для блоков 00–03 ниже есть расширенный шаблон именно под соответствующий файл.

- В следующий шаг вставляйте только нужный результат предыдущего шага, а не весь чат.

- Если Gemini не находит надёжных данных, корректный ответ — «НЕТ НАДЕЖНЫХ ОТКРЫТЫХ ДАННЫХ» + proxy/assumption с явной маркировкой.

- Расчётные показатели Excel не заменяйте выдачей Gemini. Gemini подготавливает исходные данные и доказательства, Excel выполняет расчёт.

- Для стартапа собственные CAC, churn, conversion, productivity, usage и некоторые затраты до запуска обычно BENCHMARK/PROXY/ASSUMPTION; после запуска они должны заменяться ACTUAL.

## Правила контроля источников — вставлять в первый запрос или держать как постоянную инструкцию

- Для каждого внешнего числа указывай: значение, единицу, период, географию, источник, дату публикации/обновления и прямой URL.

- Маркируй тип данных: FACT / BENCHMARK / PROXY / ASSUMPTION / INTERNAL.

- Приоритет источников: официальный НПА/регулятор/статистика → первичный сайт поставщика или публичная отчётность → отраслевое исследование → профессиональный benchmark. Блоги и агрегаторы — только как навигация к первоисточнику.

- Не выдумывай URL, дату, цитату или число. Если первоисточник не найден, пиши: «НЕТ НАДЕЖНЫХ ОТКРЫТЫХ ДАННЫХ».

- Для существенного BENCHMARK/PROXY по возможности дай 2 независимых источника или объясни, почему доступен только один.

- Не смешивай разные страны, стадии, B2B/B2C и бизнес-модели без явной поправки на сопоставимость.

- Не выдавай диапазон benchmark за факт конкретного стартапа. Неизвестные собственные показатели оставляй как BENCHMARK/PROXY до появления actual.

- Если показатель рассчитывается формулой в Excel, не пересчитывай его вместо модели: подготавливай только внешние/внутренние исходные данные для ввода и проверки.

## Как верифицировать выдачу Gemini до переноса в Excel

| Шаг | Что делать |
|---|---|
| 1. Доступность | Открой каждый URL вручную. Если ссылка не открывается или ведёт не на исходный документ — источник отклоняется. |
| 2. Соответствие | Найди на странице/в документе именно указанное число или правило. Проверь таблицу, абзац, страницу или раздел. |
| 3. Контекст | Проверь дату, географию, валюту, НДС, период, единицу измерения и объект: клиент/аккаунт/пользователь/транзакция. |
| 4. Методика | Проверь знаменатель и определение метрики. Например, CAC ≠ CPL, churn должен иметь период, цена должна быть сопоставима по billing period. |
| 5. Первичность | Если Gemini дала вторичный материал, попробуй найти первичный источник. Вторичный оставляй только с пометкой. |
| 6. Триангуляция | Для важного benchmark сравни минимум с ещё одним независимым ориентиром или диапазоном. |
| 7. Решение | Присвой статус VERIFIED / PARTLY VERIFIED / REJECTED. В Excel переносить только VERIFIED или явно помеченный proxy/assumption. |

Минимальный стандарт для существенного внешнего числа: прямой URL + проверенный контекст + дата + корректная единица + тип данных + статус VERIFIED/PARTLY/REJECTED. Если показатель влияет на valuation, runway или налог — желательно второе независимое подтверждение.

## Правило переноса в текущую модель

Файл 04 предназначен для реальные источники капитала, грантов и долга, условия и liquidity policy. В Excel переносите только те строки, которые относятся к ручным входам этого блока. Формульные выходы, межфайловые входы из предыдущих блоков и контрольные показатели вручную не заменяются данными Gemini.

Если источник слабый, но показатель нужен для сценария, оставляйте его как BENCHMARK / PROXY / ASSUMPTION, фиксируйте диапазон и план замены на ACTUAL после запуска.

Если ответ Gemini обрывается: «Продолжи только с места остановки. Не повторяй предыдущий текст и не меняй уже приведённые значения».
