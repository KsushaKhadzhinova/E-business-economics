# Блок 04. Финансирование

**Цель.** Определить потребность в финансировании и источники: вклады основателей, инвесторы, гранты, долгосрочный и краткосрочный кредит; проценты, график погашения, DSCR, runway, funding gap.

**Получает данные из:** 00–03 (операционные потоки, CAPEX, NWC).

**Передаёт данные в:** 04 → 05 (долг, проценты, поступления), 06 (взносы инвестора), 07.

**Листы Excel:** Входы, Финансирование (РУЧНОЙ ввод), Выходы, Связи, Контроль, Пояснения, Источники РБ.

**Ключевые коды (ручной ввод/основные):** `FIN.FOUNDER, FIN.INVESTOR, FIN.GRANT, FIN.LONG_RATE, FIN.LONG_IN, FIN.LONG_REPAY, FIN.SHORT_RATE, FIN.SHORT_IN, FIN.SHORT_REPAY`

**Правила и ловушки:** FIN.FUNDING_GAP = max(0; FUNDING_NEED − FUNDING_PLAN). Если gap > 0 — бизнес-план нельзя называть полностью профинансированным. Ставки — по договорам, не «из головы».

**Куда используется в курсовой (бизнес-план):** Финансовый план: таблицы Uses/Sources, потребность в финансировании, долг, runway.

## Порядок выполнения

1. Заполнить `Шаблон_входных_данных.md` (бизнес-постановка + входные данные с источниками). Сбор данных — по промптам Gemini из папки `md/` (один запрос — одно сообщение; Excel в Gemini не загружать).
2. Проверить найденные данные: открыть URL, сверить число, дату, единицу, географию; присвоить статус VERIFIED / PARTLY / REJECTED. Переносить в Excel только VERIFIED или явно помеченный PROXY/ASSUMPTION.
3. Внести значения в Excel только в ячейки ввода (жёлтые с синим шрифтом). Технические коды не переименовывать, расчётные формулы не заменять числами.
4. Обновить связанные блоки в направлении 00 → 01/02 → 03 → 04 → 05 → 06 → 07.
5. Открыть лист «Контроль» — все проверки должны быть OK (либо ВНИМАНИЕ с осознанным комментарием).
6. Выписать итоговые показатели для текста бизнес-плана (см. `../../md инструкции/02_Матрица_сборки_бизнес-плана.md`).

## Подробный алгоритм

1. Откройте лист «Финансирование». Введите по кварталам: `FIN.FOUNDER` (суммарно ≤ 20 000 USD), `FIN.GRANT` (по условиям ПВТ-поддержки), `FIN.INVESTOR` = 0, кредиты `FIN.LONG_*`/`FIN.SHORT_*` = 0.
2. Проверьте расчётные строки: `FIN.PREFIN_CASH`, `FIN.MIN_CASH`, `FIN.FUNDING_NEED`, `FIN.FUNDING_PLAN`, **`FIN.FUNDING_GAP`**, `FIN.RUNWAY_MONTHS`.
3. Если gap > 0 — решите: увеличить вклад/грант, перенести расходы, сократить команду, сдвинуть старт. Либо зафиксировать gap как открытую потребность (в записке прямо написать, что проект не полностью профинансирован).
4. Лист «Входы»: минимальный остаток денег, доля процентов и пр. — treasury-политика.
5. «Контроль» → OK; выходы идут в 05–07.

### Формулы для записки
`Funding Need = max(0; MinCash − CashBeforeFinancing)`, `Funding Gap = max(0; Need − Plan)`, `Debt Service = Principal + Interest` (при отсутствии кредита = 0).
