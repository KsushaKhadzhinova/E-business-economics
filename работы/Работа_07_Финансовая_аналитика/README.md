# Блок 07. Финансовая аналитика

**Цель.** Конечный аналитический слой: коэффициенты роста, рентабельности (ROA, ROE, ROIC), ликвидности, финансовой устойчивости (Debt/Equity, Net Debt/EBITDA, DSCR), эффективности и итоговая панель.

**Получает данные из:** Только результаты 04–06 (не 00 напрямую).

**Передаёт данные в:** Итоговые коэффициенты для текста бизнес-плана.

**Листы Excel:** Входы (годовые агрегаты), Аналитика, Связи, Квартальные данные, Итоги, Инвестиционные входы, Контроль, Пояснения, Источники РБ.

**Ключевые коды (ручной ввод/основные):** `AN.REV_GROWTH, AN.GROSS_MARGIN, AN.EBITDA_MARGIN, AN.NET_MARGIN, AN.ROA, AN.ROE, AN.ROIC, AN.CURRENT_RATIO, AN.DEBT_EQUITY, AN.NET_DEBT_EBITDA, AN.DSCR, AN.RUNWAY_MONTHS`

**Правила и ловушки:** Коэффициенты вручную не считать — только брать из «Аналитика». Debt/EBITDA и Cash Conversion интерпретировать только при положительной EBITDA.

**Куда используется в курсовой (бизнес-план):** Финансовая аналитика к прогнозу; стратегические цели (маржа, ликвидность, устойчивость).

## Порядок выполнения

1. Заполнить `Шаблон_входных_данных.md` (бизнес-постановка + входные данные с источниками). Сбор данных — по промптам Gemini из папки `md/` (один запрос — одно сообщение; Excel в Gemini не загружать).
2. Проверить найденные данные: открыть URL, сверить число, дату, единицу, географию; присвоить статус VERIFIED / PARTLY / REJECTED. Переносить в Excel только VERIFIED или явно помеченный PROXY/ASSUMPTION.
3. Внести значения в Excel только в ячейки ввода (жёлтые с синим шрифтом). Технические коды не переименовывать, расчётные формулы не заменять числами.
4. Обновить связанные блоки в направлении 00 → 01/02 → 03 → 04 → 05 → 06 → 07.
5. Открыть лист «Контроль» — все проверки должны быть OK (либо ВНИМАНИЕ с осознанным комментарием).
6. Выписать итоговые показатели для текста бизнес-плана (см. `../../md инструкции/02_Матрица_сборки_бизнес-плана.md`).

## Подробный алгоритм

1. Обновите 04 → 05 → 06, затем вставьте значения квартальных выходов в «Квартальные данные» 07 (по кодам, без изменения формул) и в «Инвестиционные входы».
2. «Аналитика» → прочитайте рост, маржи, ROA/ROE/ROIC, Current ratio, Debt/Equity, Net Debt/EBITDA, DSCR, runway. «Контроль» → OK (в файле C16 исправлен).
3. Интерпретация только словами и только при применимости (Debt/EBITDA и Cash Conversion — при положительной EBITDA).
