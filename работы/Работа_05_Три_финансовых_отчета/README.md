# Блок 05. Три финансовых отчета (ОПУ, ОДДС, Баланс)

**Цель.** Собрать интегрированную отчётность: ОПУ (Revenue → COGS → EBITDA → EBIT → Net Income), ОДДС (CFO, CFI, CFF), Баланс и налоговый контур (прибыль, убытки прошлых периодов, НДС).

**Получает данные из:** Всё из 00–04 строго через интерфейс «Входы».

**Передаёт данные в:** 05 → 06, 07 (официальные выручка, EBITDA, EBIT, чистая прибыль, cash, долг, капитал).

**Листы Excel:** Входы, ОПУ, ОДДС, Баланс, Выходы, Связи, Налоги, Контроль, Пояснения, Источники РБ.

**Ключевые коды (ручной ввод/основные):** `FS.REVENUE, FS.COGS, FS.EBITDA, FS.EBIT, FS.NET_INCOME, CF.CFO, CF.CFI, CF.CFF, CF.CASH, BS.*, TAX.*, CHECK.BALANCE`

**Правила и ловушки:** Главный контроль: CHECK.BALANCE = 0 и конечный cash ОДДС = BS.CASH. При невыполнении данные в бизнес-план переносить нельзя. Почти всё — формулы, вводятся только налоговые/учётные предпосылки.

**Куда используется в курсовой (бизнес-план):** Прогнозирование финансово-хозяйственной деятельности: три сокращённые таблицы (P&L, Cash Flow, Balance).

## Порядок выполнения

1. Заполнить `Шаблон_входных_данных.md` (бизнес-постановка + входные данные с источниками). Сбор данных — по промптам Gemini из папки `md/` (один запрос — одно сообщение; Excel в Gemini не загружать).
2. Проверить найденные данные: открыть URL, сверить число, дату, единицу, географию; присвоить статус VERIFIED / PARTLY / REJECTED. Переносить в Excel только VERIFIED или явно помеченный PROXY/ASSUMPTION.
3. Внести значения в Excel только в ячейки ввода (жёлтые с синим шрифтом). Технические коды не переименовывать, расчётные формулы не заменять числами.
4. Обновить связанные блоки в направлении 00 → 01/02 → 03 → 04 → 05 → 06 → 07.
5. Открыть лист «Контроль» — все проверки должны быть OK (либо ВНИМАНИЕ с осознанным комментарием).
6. Выписать итоговые показатели для текста бизнес-плана (см. `../../md инструкции/02_Матрица_сборки_бизнес-плана.md`).
