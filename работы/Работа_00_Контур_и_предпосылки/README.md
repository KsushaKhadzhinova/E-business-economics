# Блок 00. Контур и предпосылки

**Цель.** Зафиксировать глобальные предпосылки модели: горизонт 2026–2030, валюта, инфляция, НДС, начисления на ФОТ, налог на прибыль, WACC, Cost of Equity, terminal growth. Единый источник истины для всех блоков.

**Получает данные из:** Внешние данные (НБ РБ, налоговое законодательство, оценочная методика). Из других блоков ничего не получает.

**Передаёт данные в:** 00 → 01, 02 (инфляция), 01, 03, 05 (НДС), 02 (начисления), 05, 06 (налог на прибыль), 06 (WACC, COE, g). Напрямую в 07 передавать запрещено.

**Листы Excel:** Итоги (сводка), Допущения (ВСЯ ручная работа: жёлтые ячейки), Связи, Расчет (годовые → квартальные ставки), Выходы, Контроль, Источники.

**Ключевые коды (ручной ввод/основные):** `ENV.INFLATION_A, TAX.VAT_RATE, TAX.PAYROLL_RATE, TAX.PROFIT_RATE, VAL.WACC_A, VAL.COE_A, VAL.TERMINAL_G`

**Правила и ловушки:** Проценты в долях (20% = 0,20). WACC и Cost of Equity — разные ставки. Обязательно g < WACC и g < COE. Не вносить сюда тарифы, CAC, FTE, CAPEX. Налоговые ставки подтвердить на дату расчёта по НПА РБ.

**Куда используется в курсовой (бизнес-план):** Резюме (параметры проекта), юридический план (НДС, налог на прибыль, начисления), блок 10 (WACC).

## Порядок выполнения

1. Заполнить `Шаблон_входных_данных.md` (бизнес-постановка + входные данные с источниками). Сбор данных — по промптам Gemini из папки `md/` (один запрос — одно сообщение; Excel в Gemini не загружать).
2. Проверить найденные данные: открыть URL, сверить число, дату, единицу, географию; присвоить статус VERIFIED / PARTLY / REJECTED. Переносить в Excel только VERIFIED или явно помеченный PROXY/ASSUMPTION.
3. Внести значения в Excel только в ячейки ввода (жёлтые с синим шрифтом). Технические коды не переименовывать, расчётные формулы не заменять числами.
4. Обновить связанные блоки в направлении 00 → 01/02 → 03 → 04 → 05 → 06 → 07.
5. Открыть лист «Контроль» — все проверки должны быть OK (либо ВНИМАНИЕ с осознанным комментарием).
6. Выписать итоговые показатели для текста бизнес-плана (см. `../../md инструкции/02_Матрица_сборки_бизнес-плана.md`).
