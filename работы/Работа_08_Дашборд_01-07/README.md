# Дашборд 01–07 (упрощённая помесячная модель)

**Цель.** Упрощённая 12-месячная версия модели на 7 листах + «Дашборд» с графиками. «ИСПРАВЛЕННЫЙ_ШАБЛОН» — пустой шаблон для заполнения, «ЗАПОЛНЕННЫЙ_ПРИМЕР» — образец. К нему даётся шаблон текстового описания с маркерами [..] и картой подстановок.

**Получает данные из:** Синие ячейки на листах 01–06 (выручка, OPEX, CAPEX и остатки, финансирование, инвестиции, ставка дисконтирования, сценарный множитель FCF).

**Передаёт данные в:** Лист «Дашборд» → текст по шаблону описания.

**Листы Excel:** 01_Выручка, 02_OPEX, 03_Активы_ОК, 04_Финансирование, 05_Финрез_налоги, 06_Инвест_риски, 07_Финаналитика, Дашборд, Контроль (в шаблоне).

**Ключевые коды (ручной ввод/основные):** `(без технических кодов; ключевые ячейки: 03!H3 — начальный ЧОК, 04!J3 — начальный долг, 06!B3 — начальные инвестиции, 06!D3 — ставка дисконтирования, 06!H7:H18 — сценарий FCF)`

**Правила и ловушки:** NPV/IRR считаются по FCF до финансирования (OCF − CAPEX). Проценты — в финансовом CF. Debt/EBITDA и ROA — годовой run-rate. Единицы: BYN (не тыс.).

**Куда используется в курсовой (бизнес-план):** Резюме и финансовая часть; готовый абзац «Краткое резюме модели» из шаблона описания.

## Порядок выполнения

1. Заполнить `Шаблон_входных_данных.md` (бизнес-постановка + входные данные с источниками). Сбор данных — по промптам Gemini из папки `md/` (один запрос — одно сообщение; Excel в Gemini не загружать).
2. Проверить найденные данные: открыть URL, сверить число, дату, единицу, географию; присвоить статус VERIFIED / PARTLY / REJECTED. Переносить в Excel только VERIFIED или явно помеченный PROXY/ASSUMPTION.
3. Внести значения в Excel только в ячейки ввода (жёлтые с синим шрифтом). Технические коды не переименовывать, расчётные формулы не заменять числами.
4. Обновить связанные блоки в направлении 00 → 01/02 → 03 → 04 → 05 → 06 → 07.
5. Открыть лист «Контроль» — все проверки должны быть OK (либо ВНИМАНИЕ с осознанным комментарием).
6. Выписать итоговые показатели для текста бизнес-плана (см. `../../md инструкции/02_Матрица_сборки_бизнес-плана.md`).
