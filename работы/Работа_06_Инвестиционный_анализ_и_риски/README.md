# Блок 06. Инвестиционный анализ и риски

**Цель.** DCF-оценка: NOPAT, FCFF, дисконтирование, Terminal Value, EV, Equity Value, IRR, PP/DPP; безубыточность; доходность инвестора (IRR, MOIC); риски (R1–R6), чувствительность.

**Получает данные из:** 00: WACC, COE, g, налог; 02, 04, 05.

**Передаёт данные в:** 06 → 07 (квартальные выходы и снимок инвестиционных входов).

**Листы Excel:** Входы, Эффективность, Безубыточность, Риски (РУЧНАЯ параметризация вероятностей и шоков), Выходы, Связи, Доходность инвестора, Чувствительность, Выходы квартальные, Контроль, Пояснения, Источники РБ.

**Ключевые коды (ручной ввод/основные):** `VAL.FCFF, VAL.ENTERPRISE_VALUE, VAL.EQUITY_VALUE, VAL.IRR, VAL.PP, VAL.DPP, INV.IRR, INV.MOIC, BE.REVENUE_END, BE.SAFETY_END, RISK.EXPECTED_LOSS, RISK.ADJ_EV`

**Правила и ловушки:** FCFF = NOPAT + амортизация − CAPEX − ΔNWC. WACC > g. Не смешивать Project IRR и Investor IRR. Risk-adjusted EV = Base EV − Expected loss. Операционный EBIT без грантов.

**Куда используется в курсовой (бизнес-план):** Показатели эффективности проекта; резюме (IRR, PP, break-even, главный риск).

## Порядок выполнения

1. Заполнить `Шаблон_входных_данных.md` (бизнес-постановка + входные данные с источниками). Сбор данных — по промптам Gemini из папки `md/` (один запрос — одно сообщение; Excel в Gemini не загружать).
2. Проверить найденные данные: открыть URL, сверить число, дату, единицу, географию; присвоить статус VERIFIED / PARTLY / REJECTED. Переносить в Excel только VERIFIED или явно помеченный PROXY/ASSUMPTION.
3. Внести значения в Excel только в ячейки ввода (жёлтые с синим шрифтом). Технические коды не переименовывать, расчётные формулы не заменять числами.
4. Обновить связанные блоки в направлении 00 → 01/02 → 03 → 04 → 05 → 06 → 07.
5. Открыть лист «Контроль» — все проверки должны быть OK (либо ВНИМАНИЕ с осознанным комментарием).
6. Выписать итоговые показатели для текста бизнес-плана (см. `../../md инструкции/02_Матрица_сборки_бизнес-плана.md`).
