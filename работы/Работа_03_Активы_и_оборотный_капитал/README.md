# Блок 03. Активы и оборотный капитал

**Цель.** Рассчитать CAPEX (платформа + оборудование), амортизацию, остаточную стоимость и чистый операционный оборотный капитал (NWC, ΔNWC).

**Получает данные из:** 00: НДС; 01: AR, deferred; 02: AP, prepaids, payroll accrual.

**Передаёт данные в:** 03 → 04, 05, 06 (CAPEX, амортизация, NWC, ΔNWC).

**Листы Excel:** Входы, Цифровые активы (РУЧНОЙ ввод CAPEX и СПИ), Оборотный капитал (авто), Выходы, Связи, Контроль, Пояснения.

**Ключевые коды (ручной ввод/основные):** `ASSET.PLATFORM_CAPEX, ASSET.HARDWARE_CAPEX, ASSET.PLATFORM_LIFE, ASSET.HARDWARE_LIFE`

**Правила и ловушки:** NWC = операционные оборотные активы − операционные обязательства; ΔNWC > 0 поглощает деньги. CAPEX платформы — капитализируемые затраты на внешнюю разработку (согласовать с 02-1).

**Куда используется в курсовой (бизнес-план):** Финансовый/инвестиционный план (Uses: CAPEX, ΔNWC), производственный план (цифровые активы).

## Порядок выполнения

1. Заполнить `Шаблон_входных_данных.md` (бизнес-постановка + входные данные с источниками). Сбор данных — по промптам Gemini из папки `md/` (один запрос — одно сообщение; Excel в Gemini не загружать).
2. Проверить найденные данные: открыть URL, сверить число, дату, единицу, географию; присвоить статус VERIFIED / PARTLY / REJECTED. Переносить в Excel только VERIFIED или явно помеченный PROXY/ASSUMPTION.
3. Внести значения в Excel только в ячейки ввода (жёлтые с синим шрифтом). Технические коды не переименовывать, расчётные формулы не заменять числами.
4. Обновить связанные блоки в направлении 00 → 01/02 → 03 → 04 → 05 → 06 → 07.
5. Открыть лист «Контроль» — все проверки должны быть OK (либо ВНИМАНИЕ с осознанным комментарием).
6. Выписать итоговые показатели для текста бизнес-плана (см. `../../md инструкции/02_Матрица_сборки_бизнес-плана.md`).

## Подробный алгоритм

1. Лист «Цифровые активы»: `ASSET.PLATFORM_CAPEX` по кварталам (капитализируемая стоимость разработки платформы — из 02-1: часы функций × ставка), `ASSET.HARDWARE_CAPEX` (оборудование/ноутбуки), `ASSET.PLATFORM_LIFE` и `ASSET.HARDWARE_LIFE` (в кварталах; например 20 и 12).
2. Лист «Входы» не править — это перенос из 00, 01, 02 (AR, deferred, AP, prepaids, payroll accrual).
3. «Оборотный капитал» считает NWC и ΔNWC автоматически: отрицательный NWC (предоплаты Team/Enterprise) — нормальная картина для подписки.
4. «Контроль» → OK; `ASSET.CAPEX`, `ASSET.AMORT`, `ASSET.NET`, `WC.*` передаются в 04–06.
