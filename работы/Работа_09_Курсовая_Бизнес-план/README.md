# Работа 09. Курсовая работа: бизнес-план электронного бизнеса / цифрового продукта

## Задание

**Тема 1.** Бизнес-план электронного бизнеса в сфере … (наименование, напр. портал дополнительного образования взрослых).
**Тема 2.** Бизнес-проект цифрового продукта / услуги (напр. бронирование мест в спортивных залах).

**Цель.** Разработать бизнес-план (экономико-финансовую модель, бизнес-проект ПВТ), направленный на внедрение бизнеса на рынок.

**Задачи.**
1. Изучить подходы к формальному представлению результатов бизнес-планирования и бизнес-аналитики.
2. Изучить методики расчёта показателей бизнес-плана.
3. Разработать бизнес-план (экономико-финансовую модель, бизнес-проект ПВТ).

## Общие требования

| Параметр | Требование |
|---|---|
| Объём | Введение 1–2 стр.; основная часть до 10 стр.; заключение 1–3 стр. |
| Стиль | Научный |
| Ссылки | Обязательны |
| Источники | От 30 единиц |
| Оформление | По принятым требованиям (в презентации — «на основании …», уточнить у руководителя) |

## Структурные единицы

- **Тема 1:** титульный лист → введение → маркетинговая аналитика и аналитика рынка → экономическая аналитика → финансовая аналитика → заключение → список источников → приложения (бизнес-план; техническое задание; прототип основных страниц сайта).
- **Тема 2:** титульный лист → введение → бизнес-план / бизнес-проект ПВТ / экономико-финансовая модель → заключение → список источников → приложения (ТЗ; прототип и его ПО; …).
