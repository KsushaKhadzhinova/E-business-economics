# Чек-лист сдачи курсовой

## Содержание и объём
- [ ] Титульный лист, содержание, введение (1–2 стр.), основная часть (до 10 стр.), заключение (1–3 стр.), список источников, приложения
- [ ] Введение содержит: обоснование целесообразности, социальную и экономическую значимость, цель, задачи
- [ ] Источников ≥ 30; во всём тексте ссылки на источники; научный стиль
- [ ] Заключение: обобщающее предложение + конкретные результаты (стоимость, ФОТ, маркетинг, модель дохода, окупаемость, финансирование, IRR)
- [ ] Приложения: бизнес-план, ТЗ, прототип основных страниц сайта

## Согласованность чисел с моделью
- [ ] Выручка во всех разделах = 05 ОПУ FS.REVENUE
- [ ] Клиенты = 01 REV.SUBS; FTE/payroll = 02; CAPEX/ΔNWC = 03
- [ ] Долг 04 = долг баланса 05; cash ОДДС = cash баланса; CHECK.BALANCE = 0
- [ ] WACC > g; FCFF = NOPAT + D&A − CAPEX − ΔNWC
- [ ] Funding gap = 0 (или явно описан способ покрытия)
- [ ] Годовые потоки суммированы, остатки взяты на конец года, коэффициенты — из 07
- [ ] Прогнозные значения помечены как прогнозные; единицы и валюта едины (тыс. BYN)
- [ ] Не осталось маркеров `[…]`

## Внешнее обоснование
- [ ] TAM/SAM/SOM и Required SOM share
- [ ] CAC, churn, цены — указан тип данных (факт / benchmark / proxy / assumption)
- [ ] Налоговые ставки и режим подтверждены на дату расчёта
- [ ] Описаны: функционал, MVP, команда основателей, IP, договоры
