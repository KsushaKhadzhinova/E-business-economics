# Блок 01. Выручка и клиенты (+ 01-1, 01-2)

**Цель.** Спрогнозировать клиентскую базу, тарифы и выручку по кварталам: подписка (аккаунты × цена) + транзакции (операции × доход на операцию), НДС, дебиторка и предоплата. Вспомогательные расчёты: 01-1 (REV.SUBS по трафику конкурентов) и 01-2 (план выручки стартапа: сезонность, ramp, конверсия, churn, сценарии).

**Получает данные из:** 00: НДС, инфляция.

**Передаёт данные в:** 01 → 02 (аккаунты, транзакции, выручка), 03 (AR, deferred), 05 (выручка, НДС).

**Листы Excel:** Входы (из 00, не менять), Драйверы (РУЧНОЙ ввод), Расчет, Выходы, Связи, Контроль, Пояснения.

**Ключевые коды (ручной ввод/основные):** `REV.SUBS, REV.SUB_PRICE0, REV.TXN, REV.TXN_PRICE0, REV.AR_RATE, REV.DEFER_RATE`

**Правила и ловушки:** Цены и выручка без НДС. REV.SUBS — среднее за квартал. Для стартапа CAC/churn/конверсия — BENCHMARK/PROXY до появления ACTUAL. Рекомендуемый путь: 01-1/01-2 → числа в 01 → Драйверы.

**Куда используется в курсовой (бизнес-план):** План маркетинга, анализ рынка (Required SOM share), стратегические цели по клиентам и выручке, модель монетизации.

## Порядок выполнения

1. Заполнить `Шаблон_входных_данных.md` (бизнес-постановка + входные данные с источниками). Сбор данных — по промптам Gemini из папки `md/` (один запрос — одно сообщение; Excel в Gemini не загружать).
2. Проверить найденные данные: открыть URL, сверить число, дату, единицу, географию; присвоить статус VERIFIED / PARTLY / REJECTED. Переносить в Excel только VERIFIED или явно помеченный PROXY/ASSUMPTION.
3. Внести значения в Excel только в ячейки ввода (жёлтые с синим шрифтом). Технические коды не переименовывать, расчётные формулы не заменять числами.
4. Обновить связанные блоки в направлении 00 → 01/02 → 03 → 04 → 05 → 06 → 07.
5. Открыть лист «Контроль» — все проверки должны быть OK (либо ВНИМАНИЕ с осознанным комментарием).
6. Выписать итоговые показатели для текста бизнес-плана (см. `../../md инструкции/02_Матрица_сборки_бизнес-плана.md`).
